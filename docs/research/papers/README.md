# Research paper sources

This directory is reserved for the source papers used by the EducAgent literature review.

Five PDFs were recovered locally from the project history:

1. `01-knowledge-tracing-survey.pdf`
2. `02-survey-of-knowledge-tracing-models-variants-applications.pdf`
3. `03-deep-knowledge-tracing.pdf`
4. `05-empowering-private-tutoring-by-chaining-llms.pdf`
5. `06-genmentor-multi-agent-goal-oriented-learning.pdf`

The source PDF for paper 4, *Core Concept Identification in Educational Resources via Knowledge Graphs and Large Language Models*, was not present in the recovered project folder, although extracted text and its citation were available.

The PDFs are included for internal academic use because the destination repository is private. Before changing repository visibility or redistributing any paper, confirm both:

- the destination repository and audience; and
- that the paper's license or the team's permission allows redistribution through that repository.

When redistribution is not allowed, remove the PDF and keep only the citation, official DOI or publisher link, and the team's own notes or synthesis.
