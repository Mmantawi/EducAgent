# Architecture

This folder contains version-controlled architecture documentation for EducAgent.

- [`system-overview.md`](system-overview.md) captures the current roles, curriculum-ingestion flow, live student-learning loop, data boundaries, and open decisions recovered from the project discussions.
- [`educagent-two-stage-architecture.pptx`](educagent-two-stage-architecture.pptx) is the architecture-focused presentation recovered from the EducAgent project history.

The architecture is a draft, not a final implementation contract. Record major decisions as short architecture decision records containing context, considered options, the decision, consequences, date, and owners.
